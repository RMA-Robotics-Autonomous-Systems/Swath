      Import a layer

      GeoTIFF (.tif) comes in as a raster you can colour and shade; a single-band grid such as a multibeam DTM keeps its values, so the depth under the cursor is still a depth. GPX (.gpx) comes in as tracks, routes and waypoints.

        Projects

        Everything under projects/. Opening one loads the recordings it lists; a project only holds recordings of its own if they were copied or moved in, and those are the ones deleting it would take with it.

            WGS 84 is always the first column. Tick the grids the client wants beside it; they are suggested from where the survey is.

            Recordings

            Tick the recordings this project covers. The navigation is per recording, because the layback is a property of how that day was rigged — and it is what places the imagery, so changing it repaints the mosaic.

            Report

            The report keeps its own list of what to draw. The layer tree is a working view — a grid switched on to check a depth stays on — and a chart in a deliverable is not that. Overviews come first, one per frequency band with every recording on them, then each recording with a chart per band, then the contacts.
